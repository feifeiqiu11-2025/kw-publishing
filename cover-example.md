# Cover composition example

Use [the approved example](assets/examples/my-imagination-journey-cover.png) (kept locally only, not in the git repo, because it shows a real class's art) as a composition and style reference when creating a new book cover. This is a finished example, not a blank cover or an interior-page background.

The example combines a prominent playful title, expressive watercolor edges, character stickers with cream outlines and subtle shadows, and small tilted scene windows. Keep every character recognizable, distribute prominence fairly, avoid covering faces, and balance the collage with clear title and footer areas. Adapt placement and scale to the supplied artwork and final trim size rather than copying a fixed grid. The footer is the school/class name (`school` in book.yaml, optional) above the fixed credit **© Powered by KindleWood Studio**. Never list individual children's names on the cover; that would be far too long. They go on the Young Authors page.

For each new book, use that book's title, school name, character art and scenes. Do not reuse the example's children's characters or scenes automatically. The example has 17 characters and four scene windows; these are illustrative counts, not a required count. The user may add more artwork during iteration.

The example is an AI-composited design preview: generation may reinterpret supplied drawings. If exact preservation is needed, use a layout/compositing workflow that retains the original artwork. Always inspect the result against the supplied assets for omissions, duplicates, changed designs, legibility, and clipping before presenting it.

For About the Book, Young Authors and Keep Imagining, offer the text-free templates from [background-library.md](background-library.md), selected independently for each page. Keep all overlaid text editable and check the pale content area after layout. The titled original My Imagination Journey artwork is a cover reference, not an interior template.
